# ☀️ Дейлик — трекер задач на день

Живой daily-планировщик: задачи на сегодня, которые приятно закрывать. Один экран, ноль настроек — открыл утром, записал дела, закрыл вечером с чувством выполненного.

Учебный проект (кейс №1, курс «Фриланс 2026», урок FGIp07). Реализован по заказу-референсу FL.ru №2351967 «Простой трекер задач» как **mobile-first веб-приложение**: вместо нативной кроссплатформенности — адаптивная вёрстка, требование анимаций — исполнено.

## Возможности

- Быстрое добавление задачи одним действием (Enter или кнопка) с выбором приоритета;
- карточки задач: заметка, время, бейдж приоритета (низкий / средний / высокий);
- отметка выполнения с анимацией, секция «Выполнено сегодня», прогресс дня;
- редактирование в модальном окне, удаление с анимацией;
- **автоперенос** невыполненных задач на новый день с бейджем «перенесена», история выполненного в «Ранних днях»;
- выраженные анимации: появление и схлопывание карточек, FLIP-перелёты при сортировке, чек-анимация, рост прогресс-бара;
- данные хранятся в **localStorage** браузера — без регистрации и сервера;
- при первом запуске создаются демо-задачи, чтобы приложение не выглядело пустым;
- интерфейс на русском; mobile-first: смартфон 360 px → tablet → desktop.

## Технологии

- Node.js LTS + **Express** — сервер только раздаёт статику (никакой БД: все данные на клиенте);
- ванильные **HTML / CSS / JavaScript** — без фреймворков и сборщиков.

## Локальный запуск

Нужен Node.js 18+ ([nodejs.org](https://nodejs.org)).

```bash
npm install
npm start
```

Открой http://localhost:3001 — приложение работает, данные живут в браузере.

> Совет: чтобы увидеть приложение «как в первый раз», очистите site data для localhost в DevTools → Application → Storage → Clear site data.

## Деплой на Railway

1. **Загрузи проект на GitHub:** создай новый репозиторий (например, `daylik-tracker`) и запушь содержимое этой папки:
   ```bash
   git remote add origin https://github.com/<твой-логин>/daylik-tracker.git
   git push -u origin main
   ```
2. **Задеплой на Railway:** зайди на [railway.app](https://railway.app) под аккаунтом GitHub → **New Project** → **Deploy from GitHub repo** → выбери репозиторий. Railway сам определит Node.js и выполнит `npm install` + `npm start` (конфиг — `nixpacks.toml`, порт подхватывается из переменной `PORT`).
3. **Получи публичную ссылку:** в настройках сервиса → **Networking** → **Generate Domain** — приложение откроется по адресу вида `https://<имя>.up.railway.app`.

Если сборка упала — открой лог деплоя в Railway: чаще всего достаточно обновить зависимости (`package-lock.json` должен быть в репозитории).

## Данные и приватность

- Все задачи хранятся только в localStorage твоего браузера; сервер ничего не собирает.
- Логика смены дня: при открытии приложения в новый день невыполненные задачи прошлого дня автоматически переносятся на сегодня с пометкой «перенесена», выполненные остаются в истории «Ранних дней».
